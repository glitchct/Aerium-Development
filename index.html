Install in five steps

  1. Download the latest version from Modrinth.
  2. Open your launcher: Modrinth App, Prism Launcher, CurseForge or similar.
  3. Import the .mrpack or .zip file as a new instance.
  4. Allocate the recommended amount of RAM.
  5. Launch the game and enjoy.

Performance tips

  • Keep render distance between 8–12 chunks for the best FPS.
  • Use a shader preset that matches your hardware.
  • Close background apps to free up RAM.
  • Update your graphics drivers regularly.

Questions

Can I add more mods?
Yes, but extra mods may affect performance or stability.

Does Aerium work on low-end PCs?
Yes, it was built for and with low-end systems.

Does it work in multiplayer?
Yes, as long as the server allows the included client-side mods.
