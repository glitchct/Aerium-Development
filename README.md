# Aerium

Aerium is a modpack designed to optimize your gameplay, but still keeping good graphics.

## Features

- **Boosted performance:** Higher and more stable FPS, even on low-end hardware.
- **Great visuals:** Shaders support, improved lighting, and enhanced textures without the heavy cost.
- **Smooth gameplay:** Reduced stutters, faster chunk loading, and optimized memory usage.
- **Vanilla-friendly:** Keeps the original feel of the game while improving it.
- **Customizable:** Every visual and performance option can be tweaked to your liking.

## Requirements

| Requirement | Version |
|-------------|---------|
| Java        | 21 or newer |
| RAM         | 4 GB minimum (6-8 GB recommended) |

## Installation

1. Download the latest version from the [Releases](#) page or Modrinth.
2. Open your launcher (Modrinth App, Prism Launcher, CurseForge, etc.).
3. Import the `.mrpack` / `.zip` file as a new instance.
4. Allocate the recommended amount of RAM.
5. Launch the game and enjoy!

## Performance Tips

- Keep render distance between **8–12 chunks** for the best FPS results.
- Use a shader preset that matches your hardware.
- Close background apps to free up RAM.
- Update your graphics drivers regularly.

## FAQ

**Can I add more mods?**
Yes, but extra mods **may affect** performance or stability.

**Does Aerium work on low-end PCs?**
Yes, it was built for and with low-end systems.

**Is it compatible with multiplayer?**
Yes, as long as the server allows the included client-side mods.
